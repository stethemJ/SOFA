# Dependencies for simulations/ (ARES-based global-signal simulation).
# ARES (github.com/mirochaj/ares) is unmaintained against modern Python/
# numpy/scipy/matplotlib, so this lives in its own venv rather than the
# main project's (env/):
#
#   brew install python@3.11
#   /opt/homebrew/bin/python3.11 -m venv simulations/.venv311
#   simulations/.venv311/bin/pip install -r simulations/requirements.txt
#
# Then download ARES's lookup tables (Planck cosmology chains, halo mass
# function tables, stellar population SEDs, ~650MB): clone
# github.com/mirochaj/ares separately, run `python remote.py minimal`
# from its root (populates its own input/ dir), then copy that input/
# directory to simulations/.venv311/lib/python3.11/site-packages/input
# (that's where ares.data.ARES resolves to for a pip install).
#
# Run anything in this directory with:
#   PYTHONPATH=. simulations/.venv311/bin/python3 simulations/scripts/<script>.py
